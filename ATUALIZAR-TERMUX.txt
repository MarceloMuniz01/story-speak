StorySpeak v19 — atualização segura

1) Na pasta ~/story-speak, extraia o ZIP storyspeak-v19-atualizacao-segura.zip:
   unzip -o /sdcard/Download/storyspeak-v19-atualizacao-segura.zip -d .
   O ZIP não contém tts/, packs/ nem catalog.json.

2) Para as próximas atualizações:
   python scripts/atualizar_projeto.py

3) Para gerar áudios de novas histórias:
   python scripts/gerar_tudo.py

4) Para adicionar história:
   python scripts/adicionar_historia.py

5) Atualize GitHub Pages e reabra a PWA, talvez recarregando duas vezes.
   Downloads incluem texto, áudios e traduções offline.
